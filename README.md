# CBT Platform installer downloads

This repository is used only to host CBT Platform release assets. It does not contain application source code.

## Important

Unsigned installer builds are for controlled testing only. Windows may show an unknown-publisher warning. Do not send unsigned test installers to customers or use them with real school data. A code-signing certificate and successful clean-install validation are required before production distribution.

Each release should include the installer and its `.sha256` checksum file. Verify the checksum before running an installer.
